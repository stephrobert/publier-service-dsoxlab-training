# pub-traefik-modele

**Audience:** the learner.

Learn to read Traefik's routing model: how an entrypoint, a router and a
service chain together, and how an unqualified name resolves between two
providers.

## What you will be able to do

- Follow a request from entrypoint to router to service and backend.
- Qualify a cross-provider reference with `@file` or `@docker`.
- Recognize that an unplanned hostname must reach no application.

Two backends and a partially miswired Traefik are prepared. The task and
available paths are described in `/opt/pub-modele/README`.
