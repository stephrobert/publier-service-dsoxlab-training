# pub-traefik-acme

Configure HTTPS and secure ACME storage in Traefik, redirect HTTP, reject
obsolete TLS versions, and verify that a client receives an automatically
renewed certificate.

Guide: https://www.stephane-robert.info/docs/services/reseau/traefik-tls-acme/

```bash
dsoxlab run pub-traefik-acme
dsoxlab check pub-traefik-acme
```
