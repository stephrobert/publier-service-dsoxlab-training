# pub-traefik-acme

Configurer HTTPS et le stockage ACME de Traefik, rediriger HTTP, refuser les
anciennes versions TLS et vérifier qu'un client reçoit un certificat
automatiquement renouvelé.

Guide : https://www.stephane-robert.info/docs/services/reseau/traefik-tls-acme/

```bash
dsoxlab run pub-traefik-acme
dsoxlab check pub-traefik-acme
```
