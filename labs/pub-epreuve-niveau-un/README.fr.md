# pub-epreuve-niveau-un

Épreuve chronométrée sans indice : publiez deux services HTTPS, observez le
renouvellement automatique des certificats, bloquez les accès externes et
rétablissez le service après un redémarrage de Docker.

```bash
dsoxlab run pub-epreuve-niveau-un
dsoxlab check pub-epreuve-niveau-un
```
