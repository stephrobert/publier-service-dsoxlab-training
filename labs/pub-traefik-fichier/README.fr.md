# pub-traefik-fichier

**Public :** l'apprenant.

Apprenez à router le trafic vers un service systemd avec le fournisseur
fichier dynamique de Traefik.

## Ce que vous saurez faire

- Publier un service qui ne tourne pas dans un conteneur.
- Modifier la configuration dynamique de Traefik sans redémarrer le proxy.

Le service et le proxy sont préparés. La tâche et les chemins disponibles sont
décrits dans `/opt/pub-fichier/README`.
