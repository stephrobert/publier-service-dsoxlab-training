# pub-traefik-fichier

**Audience:** the learner.

Learn to route traffic to a systemd-managed host service through Traefik's
dynamic file provider.

## What you will be able to do

- Publish a service that does not run in a container.
- Change Traefik's dynamic configuration without restarting the proxy.

The service and proxy are prepared for you. The task and available paths are
described in `/opt/pub-fichier/README`.
