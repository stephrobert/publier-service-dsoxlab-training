# pub-socle-http

**Audience:** the learner.

Learn to read an HTTP exchange from the backend's side: what was received,
what a redirect changes, and why a retry can duplicate a write.

## What you will be able to do

- Compare the request you sent with the one the backend received.
- Predict the method a backend receives after each redirect code.
- Send a write that survives a lost response without being duplicated.

Your work happens on `edge.lab`; `challenge/README.md` describes the two files
to produce.
