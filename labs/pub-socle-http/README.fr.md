# pub-socle-http

**Public :** l'apprenant.

Apprenez à lire un échange HTTP du côté du backend : ce qui a été reçu, ce
qu'une redirection change et pourquoi une nouvelle tentative peut dupliquer une
écriture.

## Ce que vous saurez faire

- Comparer la requête envoyée à celle que le backend a reçue.
- Prévoir la méthode reçue par un backend après chaque code de redirection.
- Envoyer une écriture qui résiste à une réponse perdue sans être dupliquée.

Le travail se fait sur `edge.lab` ; `challenge/README.md` décrit les deux
fichiers à produire.
