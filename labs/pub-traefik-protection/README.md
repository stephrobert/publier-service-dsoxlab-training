# pub-traefik-protection

Secure Traefik administration over authenticated HTTPS, protect the Docker API
with a restricted socket proxy, enforce response headers, and rate-limit bursts.

Guide: https://www.stephane-robert.info/en/docs/services/network/traefik-security/

```bash
dsoxlab run pub-traefik-protection
dsoxlab check pub-traefik-protection
```
