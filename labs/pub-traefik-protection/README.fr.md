# pub-traefik-protection

Protéger l'administration Traefik par HTTPS authentifié, l'API Docker par un
proxy de socket restreint, les réponses par des en-têtes et limiter les rafales.

Guide : https://www.stephane-robert.info/docs/services/reseau/traefik-securite/

```bash
dsoxlab run pub-traefik-protection
dsoxlab check pub-traefik-protection
```
