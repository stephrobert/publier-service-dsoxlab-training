# pub-traefik-restart-recovery

**Audience:** the learner.

Learn how to configure a container restart policy and verify service recovery
after the Docker daemon restarts.

## What you will be able to do

- Configure a Compose-managed service to restart automatically with Docker.
- Verify the actual HTTP endpoint both before and after a daemon restart.

The exercise restarts Docker, not the virtual machine. Your work is under
`/opt/pub-restart`; the `README` there describes the endpoint and available
image.
