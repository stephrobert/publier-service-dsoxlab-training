# pub-traefik-restart-recovery

**Public :** l'apprenant.

Apprenez à configurer une politique de redémarrage des conteneurs et à vérifier
la reprise du service après le redémarrage du moteur Docker.

## Ce que vous saurez faire

- Configurer un service géré par Compose pour qu'il redémarre avec Docker.
- Vérifier le véritable endpoint HTTP avant et après le redémarrage du moteur.

L'exercice redémarre Docker, pas la machine virtuelle. Le travail se fait dans
`/opt/pub-restart` ; le fichier `README` qui s'y trouve décrit l'endpoint et
l'image disponible.
