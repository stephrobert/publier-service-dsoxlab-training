# pub-socle-exposition

**Audience:** the learner.

Learn to compare what a service is supposed to expose with what it really
exposes, and to close the paths that bypass the entry point.

## What you will be able to do

- List the listening ports of a host and tell who can reach each one.
- Write a flow matrix and check it against observations from two places.
- Close a port to the network without breaking the service behind the entry point.

Your work happens on `edge.lab`; `challenge/README.md` describes the file to
produce.
