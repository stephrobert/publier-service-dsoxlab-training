# pub-socle-dns

**Audience:** the learner.

Learn what happens between a name and an address: who is authoritative, who
only caches, how long an answer lives, and why a forgotten AAAA record sends
some users to the old site.

## What you will be able to do

- Tell an authoritative server from a caching resolver and query each one.
- Read a TTL and predict how long a cached answer survives.
- Switch a name between two versions, and back, covering both A and AAAA.

Your work happens on `edge.lab`; the result is checked from `poste.lab`.
`challenge/README.md` describes the two files to produce.
