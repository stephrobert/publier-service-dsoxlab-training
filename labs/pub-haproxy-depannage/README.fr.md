# pub-haproxy-depannage

Une pile saine, une panne injectée parmi routage, sonde, TLS backend, limite
ou saturation, et du bruit de configuration qui n'est la cause d'aucune. Les
tests ne connaissent pas la variante tirée : ils rejouent la recette
entière, ce qui est ce qu'un exploitant fait après une astreinte.

```bash
dsoxlab run pub-haproxy-depannage
dsoxlab check pub-haproxy-depannage
```
