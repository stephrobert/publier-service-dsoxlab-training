# pub-haproxy-mise-a-jour

La génération 1.4.2 est en service, la 1.5.0 est disponible et arrêtée, et
rien ne passe de l'une à l'autre. C'est ce que vous livrez. La validation
exécute vos exécutables et mesure entre les étapes, parce qu'une bascule ne
se constate pas après coup.

```bash
dsoxlab run pub-haproxy-mise-a-jour
dsoxlab check pub-haproxy-mise-a-jour
```
